# 代码块边角

带语言的围栏：

```js
const a = 1;

const b = '<script>';
```

无语言围栏，内含 markdown 与双链（都不该被解析）：

```
# 不是标题
- 不是列表
[[不是双链]]
<div>不是 HTML</div>
```

波浪线围栏，内含反引号围栏：

~~~text
```
inner
```
~~~

四个反引号围栏：

````md
```js
x
```
````

缩进代码块：

    第一行
    第二行

    空行之后的第三行

段落之后紧跟围栏（不需要空行）：
```
紧跟
```

围栏 info 带多个词：

```python title="x.py"
print("hi")
```

```
```
